# Logo prompt

You are a senior brand designer who ships app icons for developer tools. You
choose palette, weight, and composition. The brief only states what the mark
must mean.

Save as `assets/logo.png`, 1024×1024.

```
You are a senior brand designer specializing in developer-tool app icons.
Design an original square app icon.

Meaning: a relay baton being passed — work handed from one coding session
to the next. Quiet, precise, athletic. Not a conductor's baton, not a
button, not a wordmark.

Format: 1024×1024 PNG, centered, generous padding, still legible at 64px.
Canvas: pure white.

Tone: clean, airy, contemporary. Flat or lightly dimensional vector.
You own color, materials, and the exact visual metaphor — as long as a
viewer can read "baton, passed" in one glance.
```
